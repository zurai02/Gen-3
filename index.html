📖 Introduction

Rayfield Infinite Omni v2.0 is a massive rewrite and expansion of the original Rayfield UI library. It provides a complete, production-ready UI framework for Roblox with 50+ components, advanced features, and professional-grade performance.

What's New in v2.0?

✨ 50+ Components

Buttons, toggles, sliders, inputs, dropdowns, color pickers, text areas, and much more

🎯 Advanced Animations

30+ easing functions, keyframe animations, spring physics, and smooth transitions

🌈 Dynamic Theming

4 built-in themes with full customization, real-time theme switching

⚡ Performance Monitoring

Built-in profiler, metrics tracking, FPS monitoring, memory management

🔧 DevTools Inspector

Visual debugging, component hierarchy, performance profiling, event tracking

♿ Accessibility

Keyboard navigation, screen reader support, ARIA labels, high contrast modes

🎮 Drag & Drop

Native drag and drop support, window dragging, component resizing

📱 Responsive Design

Automatic layout adaption, grid system, flexible sizing

💾 State Management

Reactive properties, watchers, computed values, history tracking

📦 Installation

Method 1: Direct Download

  1. Download rayfield_infinite_omni_v2.lua
  2. Place in your script's directory or ReplicatedStorage
  3. Load with: local Rayfield = require(path.to.module)

Method 2: Module in ReplicatedStorage

local Rayfield = require(game.ReplicatedStorage.RayfieldInfiniteOmni)
Note: This library requires Roblox Studio or a modern Roblox game client. Make sure LocalPlayer is available before loading the UI.

⚡ Quick Start

Creating Your First Window

local Rayfield = require(game.ReplicatedStorage.RayfieldInfiniteOmni) -- Create a new window local window = Rayfield.new({ name = "My First App", size = UDim2.new(0, 600, 0, 700), theme = "dark", -- "dark", "light", or "amoled" }) -- Add a tab window:addTab("Home") -- Add components window:addLabel("Welcome to Rayfield Infinite Omni!") window:addButton({ name = "Click Me", callback = function() print("Button clicked!") end }) -- Show the window window:show()

Adding Components

-- Add toggle local toggle = window:addToggle({ name = "Enable Feature", default = false, callback = function(value) print("Toggle state:", value) end }) -- Add slider local slider = window:addSlider({ name = "Volume", min = 0, max = 100, default = 50, callback = function(value) print("Volume:", value) end }) -- Add text input local input = window:addInput({ name = "Username", placeholder = "Enter your name...", callback = function(value) print("Input value:", value) end }) -- Add dropdown local dropdown = window:addDropdown({ name = "Select Option", options = {"Option 1", "Option 2", "Option 3"}, callback = function(selected) print("Selected:", selected) end })

💾 State Management

Basic State

local stateManager = window.stateManager -- Set state stateManager:setState("playerCount", 5) -- Get state local count = stateManager:getState("playerCount") print(count) -- Output: 5

Watchers

-- Watch for state changes stateManager:watch("playerCount", function(newValue, oldValue) print("Player count changed from", oldValue, "to", newValue) end) -- Trigger the watcher stateManager:setState("playerCount", 10)

Computed Values

-- Create computed value stateManager:createComputed("playerPercentage", function() local count = stateManager:getState("playerCount") return (count / 100) * 100 end) -- Value updates automatically when dependencies change stateManager:setState("playerCount", 50) print(stateManager:getState("playerPercentage")) -- Output: 50

History

-- Get change history local history = stateManager:getHistory() for _, change in ipairs(history) do print(change.key, "changed from", change.oldValue, "to", change.newValue) end -- Clear history stateManager:clearHistory()

✨ Animation Engine

Basic Tweens

local animator = window.animationEngine -- Tween properties over time animator:tween(instance, 0.5, { BackgroundColor3 = Color3.fromRGB(255, 0, 0), Position = UDim2.new(0, 100, 0, 100), Size = UDim2.new(0, 200, 0, 200), })

Custom Easing

-- Use different easing functions animator:tween(instance, 1, { Position = UDim2.new(0.5, 0, 0.5, 0), }, Enum.EasingStyle.OutBounce)

Spring Physics

-- Create spring animation animator:spring(instance, "Position", UDim2.new(0.5, 0, 0.5, 0), 0.5, 2)

Custom Animations

-- Use custom easing function animator:customTween(instance, 1, { BackgroundColor3 = Color3.fromRGB(255, 0, 0), Size = UDim2.new(0, 200, 0, 200), }, AnimationEngine.Easing.OutElastic)

📡 Signals & Events

Component Signals

Each component has built-in signals:

local component = window:addButton({name = "Test"}) -- Connect to signals component.signals.mouseEnter:Connect(function() print("Mouse entered") end) component.signals.mouseLeave:Connect(function() print("Mouse left") end) component.signals.changed:Connect(function() print("Component changed") end)

Custom Signals

local Signal = Rayfield.Signal local mySignal = Signal.new() -- Connect listeners mySignal:Connect(function(value) print("Signal fired with:", value) end) -- Fire signal mySignal:Fire("Hello")

One-time Signals

-- Connect once only mySignal:Once(function(value) print("This will only fire once:", value) end)

⚡ Performance Monitoring

Getting Metrics

local monitor = window.performanceMonitor -- Get current metrics local metrics = monitor:getMetrics() print("FPS:", metrics.fps) print("Average Frame Time:", metrics.avgFrameTime, "ms") print("Component Count:", metrics.componentCount) print("Connection Count:", metrics.connectionCount)

Enable/Disable Monitoring

-- Enable monitoring window.performanceMonitor.enabled = true -- Disable monitoring window.performanceMonitor.enabled = false
